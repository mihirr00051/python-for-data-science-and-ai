# Variables in Python

This section covers the basics of **variables in Python**.
Variables are used to store data in memory and are a fundamental concept
in Python programming, especially important for **Data Science and AI workflows**.

---

## 📌 What Are Variables?

A variable is a name that refers to a value stored in memory.
Python uses **dynamic typing**, which means you do not need to specify
the data type explicitly.
