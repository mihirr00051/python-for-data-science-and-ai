# Chapter 03 – Datatypes in Python

This chapter covers the **core Python datatypes** that are essential for
programming, Data Science, and Artificial Intelligence workflows.

Understanding datatypes is critical for handling data, building models,
and writing efficient, bug-free code.

---

## 📌 Datatypes Covered

- Numeric Datatypes (`int`, `float`, `complex`)
- String (`str`)
- Boolean (`bool`)
- List (mutable collection)
- Tuple (immutable collection)
- Set (unique values)
- Dictionary (key–value pairs)
- NoneType (absence of value)
