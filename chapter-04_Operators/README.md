# Chapter 04 – Operators in Python (Data Science & AI)

This chapter covers **Python operators** with practical examples focused on
**Data Science and Artificial Intelligence workflows**.

Operators are used extensively for calculations, comparisons, decision-making,
and controlling logic in ML and AI pipelines.

---

## 📌 Operators Covered  ##

- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Assignment Operators
- Membership Operators
- Identity Operators

Each operator type is demonstrated using **two clear, real-world examples**.

---

## 📂 Files Included

- `arithmetic_operators.py`  
  Dataset size calculations and accuracy computation

- `comparison_operators.py`  
  Comparing model performance and loss values

- `logical_operators.py`  
  Decision-making logic for training and validation

- `assignment_operators.py`  
  Updating values during training loops

- `membership_operators.py`  
  Feature and label validation checks

- `identity_operators.py`  
  Handling `None` values and object identity
